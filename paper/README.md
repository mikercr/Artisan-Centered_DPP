# IEEE paper source

The article's LaTeX source (`article.tex`) and bibliography (`refs.bib`) are
provided here for scholarly context. Compile with an IEEEtran-compatible
LaTeX installation, for example `pdflatex`, `bibtex`, `pdflatex`, `pdflatex`.
The article proposes a semantic DPP reference model. The Go repository is a
separate practical implementation of the core traceability workflow; it is not
an RDF/OWL-based semantic reasoning platform.
